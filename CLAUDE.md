# MapDrop

Creator-first social map platform. Foodies and niche enthusiasts create beautiful categorized maps and share them via social media.

## Tech Stack
- **Frontend:** Next.js (App Router) with TypeScript
- **Backend:** Rust with Axum
- **Database:** PostgreSQL with PostGIS
- **Maps:** MapLibre GL JS
- **Repo structure:** Monorepo

## Design System
Always read DESIGN.md before making any visual or UI decisions.
All font choices, colors, spacing, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
In QA mode, flag any code that doesn't match DESIGN.md.

## Decisions System
When we are working through creating new features or fixing bugs we should write a summary of our decisions into our CHANGELOG.md file.
